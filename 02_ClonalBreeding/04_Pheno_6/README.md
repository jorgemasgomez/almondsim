# Pheno_6

32 parents; obligatory annual renewal of exactly 8 (25%).
Retain the best 24 current parents and select 8 distinct new candidates
from ACT2, even if the newcomers rank below the existing parents.

20 crosses x 25 progeny = 500 candidates.
No early seedling selection.
Other phenotyping and trial settings use the common engine.

The redesigned burn-in samples 32 distinct diploids from the completed bank150
and shares this sample across schemes within each replicate. It requires all
eight chromosomes. The historical 30-founder files are insufficient.

Run 00RUNME.R for this scenario or project main.R for all 22, with 12 replicates.
